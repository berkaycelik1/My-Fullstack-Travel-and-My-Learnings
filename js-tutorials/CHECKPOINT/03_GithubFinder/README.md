# 🔍 GitHub Profil Bulucu (API & Fetch)

Bu proje, HTML, CSS ve Vanilla JavaScript kullanılarak geliştirilmiş modern bir API projesidir. Kullanıcıların girdiği GitHub kullanıcı adını alarak, GitHub'ın resmi sunucularına asenkron (Async/Await) bir istek atar ve gelen verileri dinamik bir oyuncu kartı olarak ekrana basar.

## 🚀 Özellikler

* GitHub REST API üzerinden canlı veri çekme işlemi (`fetch`).
* **Async / Await** mimarisi ile asenkron veri yönetimi.
* Hata Yönetimi (Error Handling): Olmayan bir kullanıcı aratıldığında (404 Not Found) uygulamanın çökmesini engelleme ve kullanıcıya bilgi verme.
* Eksik verileri (Null/Undefined) "Logical OR" (`||`) operatörü ile yönetme.
* CSS Flexbox ile modern, yuvarlak hatlı ve gölgeli (box-shadow) şık kart tasarımı.
